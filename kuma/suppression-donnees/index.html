Suppression des données — Kuma

Dernière mise à jour : 15 février 2026

But : Cette page explique comment demander la suppression des données éventuellement associées à votre utilisation de l’application Kuma.
Note : Kuma ne demande pas d’adresse e-mail dans l’application.

1) Comment demander la suppression

Envoyez un e-mail à ariskouadio@gmail.com avec l’objet : Suppression des données — Kuma.

2) Informations à inclure

  • Votre appareil : modèle (ex. TECNO…), version Android (si possible).
  • La langue utilisée dans l’app (ex. Dioula, Baoulé, Agni, etc.).
  • Ce que vous voulez supprimer (ex. “supprimer progression et préférences”).
  • Optionnel mais utile : une capture d’écran de l’écran “Profil”/“Paramètres” si l’app affiche un identifiant technique, ou toute info permettant de retrouver les données.

3) Quelles données peuvent être concernées

Selon votre utilisation, les données pouvant être supprimées peuvent inclure :

  • Données d’usage : progression, leçons terminées, activités réalisées.
  • Préférences : langue d’interface, langue cible, réglages liés à l’expérience.
  • Données techniques : diagnostics/logs si activés.

4) Délai

Nous traitons généralement les demandes sous 30 jours.

5) Contact

Éditeur : Nexa Digital
Support : ariskouadio@gmail.com

Data deletion — Kuma

Last updated: February 15, 2026

Purpose: This page explains how to request deletion of data that may be associated with your use of the Kuma app.
Note: Kuma does not ask for an email address inside the app.

1) How to request deletion

Email ariskouadio@gmail.com with the subject: Data deletion — Kuma.

2) What to include

  • Your device: model and Android version (if possible).
  • Language used in the app (e.g., Dioula, Baoulé, Agni, etc.).
  • What you want deleted (e.g., “delete progress and preferences”).
  • Optional: screenshots of Settings/Profile if the app shows a technical identifier, or anything that helps locate data.

3) What data may be affected

  • Usage data: learning progress, completed lessons, completed activities.
  • Preferences: UI language, target language, experience settings.
  • Technical data: diagnostics/logs if enabled.

4) Timeline

We typically process requests within 30 days.

5) Contact

Publisher: Nexa Digital
Support: ariskouadio@gmail.com
